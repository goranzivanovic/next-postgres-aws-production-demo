# Portfolio case study

Title: Production-Ready Next.js + PostgreSQL + AWS Demo

I built a client-safe full-stack demo showing multi-tenant PostgreSQL isolation, migrations, API routes, explicit human approval for writes, Docker reproducibility, automated checks, backup/restore procedures, CI release gates, and an AWS deployment blueprint using RDS, Secrets Manager, IAM and CloudWatch.

The repository is independent from proprietary systems so the implementation can be reviewed and explained during a technical interview.
